# ¿Qué es esto?
Este es un proyecto pequeño que tiene como objetivo guardar este pequeño programa.

Su única funcionalidad es ser un renombrardor de archivos comodo para mi. Aunque sería interesante que para alguien más también tuviese ese nivel de comodidad.

# Forma de usarse
El programa al igual que su código es sencillo y pequeño, también es sencillo de usar.. Creo.
El programa se usa así:

* "[ejecutable] [directorio] [modo] [nuevo nombre] [extension]"

Aunque si fuera un uso real sería algo como

* "renombrar_archivos.exe C:\Users\NOMBRE\Desktop\mi_carpeta -A "[FILE_NAME] hola mundo [EXTENSION]" txt"

Lo que hará será renombrar todos los archivos .txt, con el nombre que ya tenían más el texto que se le agregó, y por último su extensión correspondiente.
